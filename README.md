# Uni-pars

Android-приложение для мониторинга сайтов. ИИ (по умолчанию Google Gemini 3.5 Flash-Lite, можно
переключить на Anthropic Claude; ваш API-ключ) **один раз** настраивает,
что и как парсить. После этого приложение собирает данные в фоне **без ИИ и без токенов** и
присылает уведомления.

Подробный дизайн: [docs/design.md](docs/design.md).

## Как это работает

1. **Новый рецепт.** Вы вводите адрес страницы и описываете, что отслеживать. Страница открывается
   во встроенном браузере, и вы касаетесь нужных элементов.
2. **Разведка без ИИ.** Приложение проверяет `robots.txt`, заголовки, антибот-защиту, JSON-LD,
   встроенный JSON, скрытые JSON-API (перехват fetch/XHR), RSS и время ответа.
3. **ИИ (только здесь тратятся токены).** По желанию ИИ ищет сведения о сайте в интернете. Затем
   он составляет рецепт (селекторы, ключ записи, проверки, условия уведомлений) и предлагает
   настройки. Приложение сразу прогоняет рецепт на странице. Если рецепт не сработал, ошибка
   уходит обратно ИИ (до 3 попыток).
4. **Вы проверяете превью** и меняете настройки: интервал, разброс, тайм-ауты, повторы, лимит
   запросов, тихие часы, Wi-Fi или зарядку, robots.txt, поведение при капче, условия уведомлений.
5. **Фон.** WorkManager (минимум 15 минут) загружает страницу через HTTP с условным GET или через
   WebView. Затем он применяет рецепт, сравнивает с прошлым состоянием и уведомляет о новых
   записях, изменениях, исчезновении записи, пересечении порога или найденном тексте.
6. **Капча или проверка браузера.** Рецепт встаёт на паузу, приходит уведомление. Вы проходите
   проверку во встроенном браузере (cookie общие с фоновыми запросами), и сбор продолжается.
7. **Сайт изменился.** Приходит уведомление «перестал работать» с кнопкой «Починить с ИИ».
   Токены тратятся только по нажатию.

## Модули

| Модуль | Что внутри |
|---|---|
| `engine` | Чистый Kotlin/JVM: формат рецепта, извлечение (CSS/Jsoup, JSON path, JSON-LD, `__NEXT_DATA__`), валидация, diff и условия, детектор капчи и антибота, разведка сайта, robots.txt, очистка HTML для ИИ. Покрыт тестами. |
| `ai` | Генерация и починка рецептов: Gemini (REST API, структурированный JSON, поиск Google) и Claude (Anthropic Java SDK), строгая JSON-схема, цикл самопроверки, защита от подмены инструкций, оценка стоимости. |
| `app` | Android: Compose UI (русский и английский), Room, WorkManager, уведомления, WebView (выбор элементов, перехват XHR, проверки), ключи в Android Keystore, виджет, экспорт и импорт. |

## Возможности

- Gemini по умолчанию (`gemini-3.5-flash-lite`), Claude на выбор. Ключ и модель задаются
  отдельно для каждого провайдера. Есть оценка стоимости в долларах и месячный лимит расходов.
- Ссылку можно отправить через «Поделиться» из браузера: мастер откроется сразу с этим адресом.
- Личные данные (e-mail, телефоны, номера карт, значения форм) скрываются перед отправкой в ИИ.
  Содержимое страницы передаётся модели как недоверенные данные. Если ИИ предлагает источник на
  другом сайте, нужно явное подтверждение.
- Запросы к одному сайту от всех рецептов идут по очереди, с паузой и общим суточным лимитом.
- Раз в сутки приложение удаляет данные старше 90 дней, перечитывает robots.txt, предупреждает,
  если Android откладывает проверки, и ищет обновление в GitHub Releases.
- Экспорт и импорт рецептов в JSON, выгрузка собранных данных в CSV.
- Виджет на рабочий стол с состоянием рецептов.
- Отчёт о сбое хранится только на устройстве. Отправить его можно из настроек.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android.yml`) при каждом push. Готовые
`debug`- и `release`-APK лежат в артефактах запуска (Actions → запуск → Artifacts). Тег `v*`
публикует APK в GitHub Release.

CI запускает тесты (`engine`, `ai`, `app` на Robolectric) и Android Lint. Отчёты и схемы Room
выкладываются в артефакт `reports-N`.

### Подпись

Без постоянного ключа каждая сборка подписана временным ключом, и новую версию нельзя
поставить поверх старой. Создайте ключ один раз:

```bash
./scripts/make-release-key.sh            # создаст uni-pars-release.jks и .b64
```

Затем добавьте секреты репозитория (Settings → Secrets and variables → Actions):
`SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.
Сохраните `.jks` и пароль в надёжном месте: если их потерять, пользователи не смогут обновить
приложение.

Локально нужны JDK 17 и Android SDK:

```bash
./gradlew :engine:test :ai:test     # тесты, Android SDK не нужен
./gradlew :app:assembleDebug        # APK
```

## Ограничения

- Интервал не меньше 15 минут: это ограничение WorkManager.
- Оболочки производителей (MIUI, EMUI, One UI) могут убивать фоновые задачи. В настройках
  приложения есть кнопки для снятия ограничений батареи.
- Приложение не обходит капчи и защиту. Их проходит человек.
- Сайты с жёсткой защитой от ботов могут не работать.
